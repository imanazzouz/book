## التشغيل

```bash
npm ci
npm run dev        # http://localhost:3000 → يوجّه إلى /ar
npm run lint       # ESLint 9 (flat) + next/core-web-vitals + TypeScript
npm run typecheck  # tsc --noEmit (strict)
npm test           # Vitest (28 اختبارًا)
npm run build      # بناء إنتاجي
```

لا يحتاج المشروع أي متغيّر بيئة في المرحلة 2. الأسماء المستقبلية موثّقة في `.env.example` فقط (بلا قيم).

## ما هو منفّذ الآن

- واجهات عامة كاملة بثلاث لغات: الرئيسية، السوق (بحث/فلاتر/فرز/ترقيم)، التصنيفات، صفحة تصنيف، صفحة منتج، صفحة متجر، من نحن، التواصل، FAQ، انضم كمزارع، الخصوصية، الشروط، الدخول، 404، صفحة خطأ.
- RTL حقيقي للعربية وLTR للفرنسية/الإنجليزية (اتجاه محسوب على الخادم).
- نظام تصميم من الهوية المعتمدة (ألوان، خطوط محلية، مكوّنات، حالات Loading/Empty/Error).
- رؤوس أمان + CSP، `noindex` للصفحات الخاصة، تحقق وتنقية لمعاملات البحث، sitemap/robots.
- 4 صور فوتوغرافية حقيقية مرخّصة (Unsplash) بلا أشخاص أو حيوانات — [سجل التراخيص](./docs/asset-licenses.md).

**غير منفّذ بعد (بقرار):** المصادقة، قاعدة البيانات، السلة والطلبات، لوحات المزارع والإدارة. لا توجد أزرار كاذبة: كل ما لم يُنفَّذ يظهر معطّلًا مع سبب واضح، والمنتجات تُعرض بحالة فراغ صادقة لأن **قاعدة البيانات لا تحتوي أي بيانات تجريبية**.

## المبادئ

1. **لا بيانات وهمية:** البذور بيانات مرجعية فقط (69 ولاية، 1541 بلدية، تصنيفات، توصيل).
2. **لا صور مولَّدة بالذكاء الاصطناعي ولا كائنات حيّة** في أي جزء من المنصة.
3. **الخادم مصدر الحقيقة** للأسعار والمخزون والإجماليات والصلاحيات.
4. **لا أسرار في المستودع.**
5. **لا ادعاء نجاح** بدون مخرجات اختبار فعلية.
